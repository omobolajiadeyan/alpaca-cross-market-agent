# Project provenance

CrossSignal is an original project by **Omobolaji E Adeyan**.

## Initial foundation

The project entered the hackathon with an early research foundation: Alpaca MCP connectivity, cross-market data collection, Claude-assisted thesis synthesis, defined-risk portfolio construction, basic audit logging, and a Streamlit prototype.

## Hackathon development

During the official event window, the prototype was materially expanded into the submitted system:

- Option-Greeks capture and delta/gamma/vega stress scenarios
- Execution-quality, margin, drawdown, and evidence-completeness gates
- Decision Replay and proof-of-abstention experiences for judges
- Catalyst classification using bounded Alpaca News context
- Partial-exposure recovery planning with explicit paper-only approval
- Portable, secret-free evidence receipts
- Five-day walk-forward scoring with agent, inverse, and cash comparisons
- NIST AI RMF- and SSDF-aligned security controls and documentation
- Public read-only mode and strict Alpaca paper-endpoint enforcement
- Expanded responsive presentation and automated verification

The repository preserves its authentic Git history. The submission claims only the functionality demonstrated by the code, tests, and application.
